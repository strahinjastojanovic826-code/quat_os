# 🌀 QuatEngine 4^8 — Quaternary Operating System & Hardware Simulator

> **An experimental Base-4 (4-state) Operating System & Simulator featuring low-level hardware emulation, voltage-based voice modulation, celebrity legal engines, and football tactical overthinking algorithms.**

---

## 💡 About The Project

**QuatEngine 4^8** is a hardware and OS simulation environment built around **Quaternary Logic (Base-4)**. Instead of traditional binary ($0$ and $1$), every signal, register, and audio state is represented by 4 distinct voltage levels: 
- **$Q_0 = 0.0\text{V}$**
- **$Q_1 = 1.1\text{V}$**
- **$Q_2 = 2.2\text{V}$**
- **$Q_3 = 3.3\text{V}$**

> ⚠️ **Language & Style Note:** The interface intentionally uses a **Balkanized Hybrid UI (English / Serbian / Spanish)** to blend low-level hardware design with pop-culture satire and humor.
